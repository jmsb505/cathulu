## Baseline and scope

- PLAN-020 M50 is the governing milestone. This packet delivers its optional repository association and non-code project behavior as an independently validated first slice.
- Existing repository registration must retain project IDs, canonical paths, Git refresh behavior, logical PM keys, and checkpoint history.
- A non-code project has no repository path, defaults to private, and can own ordinary objectives, tasks, and provider-free checkpoints. Creating one does not inspect Git or start a provider.
- Personal memory categories and facts are not introduced. P-Q2 stays open; no provider receives non-code project context.
- Git-only operations must return a stable `project_has_no_repository` outcome or skip the project. Dispatch admission must reject non-code work before queue/provider start.
- Private non-code data is available through the unscoped local management surface only. Role capabilities must not read it. Main's project list and portfolio/resource projections include shared projects only; private project IDs and metadata are omitted.
